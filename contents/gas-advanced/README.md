# GAS学習（応用編）

Google Apps Script を使った Web アプリケーション開発を学びます。HTML/CSS による画面作成の基礎から、スプレッドシート・フォームのデータを反映した Web アプリの公開までを扱います。

## フェーズ一覧

| フェーズ | タイトル | 週数 | 概要 |
|---------|---------|------|------|
| [Phase 1](./phase1.md) | Web開発の基礎 | 3週 | GASによるWebアプリ公開の仕組みとHTML/CSSの基礎を学びます |
| [Phase 2](./phase2.md) | Webアプリ公開 | 2週 | スプレッドシート・フォームのデータをWebアプリに反映します |

## コンテンツ構成
